# Provenance

Prepared on **2026-11-07** for Matthew Chenoweth Wright at his request. This is an
AI-assisted repository about an AI-generated image and the human–assistant
exchange around it. It is not a transcript of an independent research study.

## Images

| File | Origin | Treatment in this package |
|---|---|---|
| `room-original.jpeg` | Empty-room image uploaded by Matthew in this conversation | Original supplied bytes, copied unchanged |
| `room.png` | Image generated by editing that supplied room according to a personalized prompt | Generated bytes copied unchanged; no new image generation or pixel editing for this ZIP |

The original photograph's creator and reuse license were not supplied. The image
files are included for the requested repository package. This is not a statement
that all underlying rights have been independently cleared. See
[LICENSE_NOTICE.md](LICENSE_NOTICE.md).

[IMAGE_PROMPT.txt](IMAGE_PROMPT.txt) preserves the editing instruction. It requested
a patterned rug, three connected work areas, a clear central path, warm lighting,
scientific and musical references, and no people. It did not request a Lebowski
reference. Image generation need not satisfy every detail of a prompt exactly.
The supplied images, rather than the prompt, are authoritative about visible pixels.

The website's original/generated switch is a presentation control. It does not
modify either file. The two images differ in many respects and cannot serve as a
controlled rug-only intervention.

## Catalog

The source is the 72-entry inventory produced in the conversation after the image.
`inventory.json` preserves its identifiers and subjects. Descriptions have been
edited for standalone clarity and to mark grouped objects and uncertain readings.
`INVENTORY.md` and `inventory.js` are generated from that JSON.

- **visible**: a direct visual reading at ordinary image scale; not a claim of real-world ownership.
- **grouped**: several visible things occupy one catalog entry.
- **interpretive**: identity or significance involves a more uncertain reading.

These tags are editorial annotations. No object detector or species classifier
was run. “Full inventory” means the full prior list, not guaranteed exhaustive
segmentation of every pixel or object in the scene.

## Integrity and source history

`source-manifest.json` records image SHA-256 hashes and the inspected primary-source
blob identifiers. `SHA256SUMS` records all distributable files other than itself.
Neither hash file verifies the truth of a claim or the rights to an image; hashes
help detect changes to bytes.

The external READMEs were inspected during preparation. Their Lean builds and
benchmarks were not rerun. Local package validation is reported separately in
[VERIFICATION.md](VERIFICATION.md).
