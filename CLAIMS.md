## How to extend this ledger

Add a new claim before adding a new result. State the subject, the evidence, the
scope, and any missing bridge. Keep failed tests and open obligations visible.
If an image or narrative is doing the work, call the claim an interpretation.
If code is doing the work, record the executed version and command. If it is a
joke, leave the label attached when quoting it elsewhere.
